## ✨ 功能

- 📚 **8079 词** 核心/高频/基础/进阶四级分类
- 🔍 **词库管理** — 搜索、添加自定义词、批量导入、删除、导出
- 🃏 **3D 翻卡动画** — Markdown 式标记认识/不认识
- ⏱ **间隔复习** — 不认识的词自动进入复习队列
- ★ **收藏系统** — 随时复习收藏单词
- 🎯 **学习统计** — 连胜 / 每日计数 / 进度追踪
- 🎨 **6 套主题** — 暗绿 · 暗蓝 · 暗紫 · 暖琥珀 · 玫瑰 · 浅色
- 🔊 **朗读发音**
- 🕵️ **老板键** `Ctrl+Shift+H`
- 🖱 **迷你模式** — 最小化为单行
- ⌨️ **自定义快捷键** — 改键位工具
- 💾 **完全离线** — 进度存本地，隐私安全

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `Space` / `↑` | 翻转卡片 |
| `L` / `→` | 认识 |
| `H` / `←` | 不认识 |
| `S` / `↓` | 跳过 |
| `P` | 朗读 |
| `M` | 迷你模式 |
| `Backspace` / `Z` | 上一张 |
| `Ctrl+Shift+H` | 老板键隐藏/显示 |

## 🛠️ 工具（在文件夹里双击）

- `改键位.bat` → 自定义快捷键
- `清空记忆.bat` → 重置学习进度
- `管理词库.bat` → 搜索全库 / 添加 / 删除 / 导出
