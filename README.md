## 🔧 源码运行

```bash
git clone https://github.com/lybbbb-aaa/cijing-v1.0.git
cd cijing-v1.0
npm install
npm run build     # src/ → widget.html，并同步到 dev / dist
npm run dev       # 直接启动
npm test          # 核心逻辑单元测试
npm run vocab     # 重建词库（需要 data/ 下的源数据）
npm run release   # 打包免安装版到 release/
```

**改前端请改 `src/`**（`widget.template.html` / `widget.base.css` / `widget.theme.css` / `widget.js`），
根目录的 `widget.html` 是 `npm run build` 的生成物。

> `devDependencies` 里锁定了 `electron@22.3.27`（与随包运行时的版本一致）。
> 如果你不想重新下载 Electron，可以不动 `node_modules`。
