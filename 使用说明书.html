1. 安装与启动

1
解压下载的 zip 包到任意目录（桌面、D盘都行）
2

3
屏幕右上角出现半透明单词卡片 → 开始学习
退出请点击卡片右上角 ✕ 按钮，或右键任务栏图标退出。

6. 词库管理

双击文件夹里的 manage-vocab.bat 打开词库管理工具。

🔍 搜索词库

  1. 点顶部「🔍 搜索」标签
  2. 输入关键词（英文或中文均可）
  3. 点「搜索」按钮或按回车
  4. 可按分类过滤：全部 / 核心 / 高频 / 基础 / 进阶 / 自定义
  5. 每个结果行有「删除」按钮，屏蔽不需要的词
  6. 点击单词可查看详情弹窗

➕ 添加单词

  1. 点「＋ 添加」标签
  2. 填写英文单词和中文释义（必填）
  3. 可选填：词性、音标、英文释义、例句
  4. 选择分级（核心 / 高频 / 基础 / 进阶）
  5. 点「添加单词」
添加后需重启词境才能看到新单词。

↑ 批量导入

每行一个词，格式：

persevere,坚持；不屈不挠,h

分级可选：c(核心) / h(高频) / b(基础) / a(进阶)

↓ 导出词库

支持 CSV（Excel可打开）和 JSON 格式，可保存到文件或复制到剪贴板。

7. 自定义快捷键

双击文件夹里的 改键位.bat：

  • 每个功能可绑定多个按键
  • 点击输入框 → 按下你想要的快捷键
  • 修改后自动保存，立即生效

8. 清空学习记录

双击 清空记忆.bat：

选项清除内容
清空学习进度认识/不认识/收藏/连胜/今日计数
仅清空收藏只清除收藏列表
全部清空回到全新状态
⚠ 操作不可撤销，请确认后执行。

9. 常见问题

问题解答
打开后看不到窗口？检查右上角；尝试按 Ctrl+Shift+H 切换显示
添加的单词没出现？添加后需要重启词境
进度丢失了？检查 AppData\Roaming\ielts-widget\progress.json 是否被删
如何彻底卸载？删除文件夹即可；清理记录删 ielts-widget 目录
支持 Mac 吗？当前仅 Windows，Mac 用户可自行打包源码
切换词库分类后词太少？选择「全部」分类包含完整 8079 词
朗读没声音？检查系统语音设置，确保有英文语音包
